# 德州扑克规则与庄家流程助手

本模式采用常见的无限注德州扑克：每人两张底牌、五张公共牌，从七张中取最佳五张；花色不决定胜负。实物牌在线下发放和比较，围桌计算投入、底池与积分，并提醒下一步。

## 本桌约定

本应用按线下聚会约定采用逆时针座位、发牌与行动顺序；方向是本桌约定，其余下注和底池流程沿用下面的规则。

默认初始积分 1000、小盲 5、大盲 10、前注 0。创建时可修改；前注启用后由每位玩家支付。积分为整数，本局只能使用开局时已有的积分，补分、盲注与座位调整在局间进行。

按钮庄位决定顺序，发牌协助者负责确认流程。房主始终有协助权限，也可在局间指定一位在座玩家协助；协助者可以正常玩牌。多人桌小盲、大盲在按钮沿行动方向的下一位依次落位；双人按钮兼小盲，翻牌前先行动，翻牌后大盲先行动。下一局轮转大盲，并据此确定按钮；三人转双人避免连续付大盲。

## 按提醒推进

1. 按现实逆时针排列座位，确认积分；所有人准备后，房主或协助者开局，系统收前注和盲注。
2. 从按钮沿行动方向的下一位开始逆时针发两张底牌，协助者点击“底牌已发好”。双人桌大盲先收牌。
3. 翻牌前从大盲沿行动方向的下一位开始行动；双人小盲先行动。大盲在无人加注时仍有过牌或加注机会。
4. 行动结束，助手暂停并提醒烧一张牌、发三张翻牌。协助者确认后，从按钮沿行动方向的下一位仍在场且有积分者开始行动。
5. 以同样方式确认转牌和河牌，每次先烧一张、再发一张。
6. 摊牌时按主池、边池逐池选择赢家，平牌多选；核对汇总弹窗后确认全部派奖。只剩一人未弃牌时自动结算。

协助者可代记当前玩家已在线下明确的动作。撤回恢复积分和流程，实物牌也须同步核对；误开局可撤销本局、退还投入后重新准备。

## 下注与全下

最低开注为大盲，完整加注的增量至少等于上一次完整下注或加注的增量。输入“加到”代表本轮累计投入：已经投 10、加到 30，实际再扣 20。

积分不足时可短额全下。它会提高跟注额，但不会自动开放已经行动者的加注权；若多个短额全下累计达到该玩家面对的完整增量，才重新开放。已行动者可以跟注或弃牌。仅剩一位有积分、其余人全下时，不允许继续对空边池下注；仍需回应实际欠跟注额，随后亮牌并按提醒发完公共牌。

## 底池与派奖

系统按投入层级计算主池和边池。全下玩家只能争夺自己投入覆盖的底池；弃牌投入保留，弃牌者不能获奖。无人匹配的净投入自动退还，记录在奖池明细中。每个底池单独判断，平牌均分；整数除不尽的余数，按按钮沿行动方向的下一位逆时针发给该池获胜者。

例如甲投入 50、乙投入 100、丙投入 150 且均未弃牌：先退丙 50；主池为 150，甲乙丙都有资格；边池为 100，只有乙丙有资格。房主不能把边池发给甲。

各局保存逐池派奖、退还、投入明细和每人得失，刷新或重启后继续保留。局间改名不改变已结算记录中的姓名。

## 规则来源与边界

发牌和下注流程参考 [PokerStars 德州扑克规则](https://www.pokerstars.com/poker/games/texas-holdem/)；加注权、双人位置、逐池结算与奇数筹码参考 [Poker TDA 2026 规则](https://www.pokertda.com/view-poker-tda-rules/)。这些资料用于确定常见流程，本应用的具体约定以以上说明和房间设置为准。

当前支持单次公共牌发牌、每人前注和固定盲注。暂不含自动牌型识别、锦标赛盲注计时、大盲代付前注、强制额外盲注、多次发牌、抽水和误发牌自动裁定；这些需要整桌在线下协商，不应当作已实现功能。

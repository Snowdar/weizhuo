# 炸金花网络玩法参考（未应用）

查阅日期：2026-10-03。本文件仅为资料整理，不是程序配置，也不改变现有房间规则。

## 参考来源

- [16VS 平台：炸金花规则](https://www.16vs.com/web/skin/help/zjhHelp.jsp)：多人三张牌玩法说明，使用去掉大小王的 52 张扑克牌；其平台设定为 2–4 人，最后两人可选择开牌，也有封顶后开牌的规则。
- [另一平台的三张牌玩法说明](https://www.astar222.com/gameRule/msc/win3cards.html)：该页面实际上是“龙／凤”两家比较的版本，不等同于本项目的多人轮流游戏；仅用于确认牌型约定存在不同版本，不应直接导入。

## 可参考的共同牌型

两份说明均列出豹子、同花顺（顺金）、同花（金花）、顺子、对子、散牌（单张）。基本大小顺序为豹子、顺金、金花、顺子、对子、单张。同牌型通常继续比点数，对子先比对子再比单牌。

## 需要由整桌另行约定的差异

- A23 的位置：16VS 将其放在 AKQ 之后；第二份说明将其放在最小顺子的位置。
- 特殊 235：16VS 的牌型表未单列此项；第二份说明包含非同花 235 胜豹子的特殊规则。
- 人数、比牌费用、允许比牌的轮数、是否允许开暗牌，以及是否封顶后自动开牌，不能从上述平台说明推定为统一标准。

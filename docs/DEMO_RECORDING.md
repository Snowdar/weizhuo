# 演示录制与剪辑

- 在独立临时数据目录启动服务，浏览器使用 `/test/`。不得操作正式房间，不将数据库、私人二维码及临时原始录制提交仓库。
- 两位虚构玩家使用独立 device 身份，竖屏 393 × 852。房主启用沉浸牌桌，另一玩家保留普通视图；截图后核对实际尺寸，不能以设置成功代替画面确认。
- 使用 Agent 浏览器工具真实点击：准备、开局、底牌完成、加注与跟注、各街发牌与行动、选赢家、结算。持续同步捕捉两端；不得用静态截图轮播冒充实际操作。
- 发布成片 1280 × 1510，两个竖屏并排，上方分别标注编号、姓名及全屏／普通视图。介绍部分单独展示竖屏启动、服务、大厅与规则设置。
- 前段旁白用本地 Qwen3-TTS Serena 合成。开局后停止介绍，只保留房主播报；保存服务端实际返回 WAV 和生成时间，不把后期同步音轨称为设备扬声器回录。

## 一分钟版本（2026-10-11）

- 先更新正式 Serena 库，再录制独立测试牌局；本次不构建 App，因此不能将视频标为新真机版本验收。
- 约 56 秒，1280 × 1510；两个 393 × 852 竖屏并排，左侧房主全屏，右侧普通玩家。开局积分各 20，小盲 5／大盲 10，2 号玩家 All-in 剩余 15，1 号玩家弃牌；退回未匹配投入后派奖 20，最终 10／30，总分 40。
- 对局连续采集真实 UI 帧，保留动作、确认、同步与派奖变化，仅删去操作间等待空档；不是设备屏幕录像。大厅和创建规则采用当前浏览器实拍定帧，未变化的启动／服务段复用旧模拟器录像。
- 8 条播报来自正式声音库，经服务实际返回并保存；旁白 5 段来自同一条连续 Serena 源录音的连续切片，保持原速和音高，减少句间声线变化。游戏期间无介绍旁白，结尾再加邀请语。音轨后期同步，不宣称是扬声器回录。
- 剪辑需要 FFmpeg、NumPy 和 SciPy，当前默认使用 macOS 系统黑体字体。
- 精简剪辑使用 `scripts/render-promo.py`。输入 `edit.json` 按顺序列出段落的 `label`、`duration`、`kind`（native／still／paired）、`title`、可选 `narration`；native 提供 `sourceStart`，still／paired 提供实际 `frames`（at、left、right），paired 的 `voices` 记录 file、text、offset。另需 narration.json、相应 WAV 及原生录像。

```sh
python scripts/render-promo.py /path/to/captures --native-intro /path/to/native-intro.mov
```

- 输出 MP4、封面、逐段时间线与字幕；工具拒绝语音重叠、采样率不一致及削波。发布前人工检查首尾、游戏操作、字幕、All-in、结算与两端完整构图。
